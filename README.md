# Классификатор обращений студентов

CLI-агент для автоматической классификации обращений студентов и формирования черновиков ответов на русском языке.

## Описание

Проект решает проблему первичной обработки обращений студентов в учебных заведениях. Система автоматически определяет категорию обращения и формирует черновик ответа, что позволяет сократить время на обработку типовых запросов.

**Для кого:** сотрудники деканата, справочных служб, технической поддержки учебных заведений.

## Что реализовано

- **Классификация** обращений на три категории: `справка`, `жалоба`, `другое`
- **Генерация ответов** на русском языке с учётом категории обращения
- **Два режима работы:** правила (без API) и LLM (Google Gemini)
- **Безопасный fallback:** при ошибках LLM или низкой уверенности система использует локальные правила
- **Память:** история обработки обращений сохраняется в `memory.json`
- **Валидация:** каждое обращение проверяется на корректность категории, наличия ответа и диапазона уверенности

## Как работает решение

```
messages.txt → Загрузчик → Классификатор → Валидация → Генератор ответов → Память → CLI
```

1. Система читает обращения из `messages.txt` (по одному на строку)
2. Каждое обращение классифицируется в одну из трёх категорий
3. На основании категории формируется черновик ответа
4. Результат проверяется на корректность
5. Валидные обращения сохраняются в `memory.json`
6. Результат выводится в CLI

## Технологии

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.10+ |

| Классификация | Правила (ключевые слова) + LLM |
| Тестирование | pytest |
| Хранение данных | JSON (локально) |

## Установка и запуск

### Быстрый старт (без API)

```bash
# Клонирование репозитория
git clone <repository>
cd <repository>

# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск (режим правил, без API)
python main.py
```

### Запуск с LLM (Google Gemini)

```bash
# Получение API ключа: https://aistudio.google.com/apikey

# Установка ключа
export GEMINI_API_KEY=ваш-ключ

# Запуск в LLM-режиме
python main.py --llm
```

Или создайте файл `.env` (см. `.env.example`):

```bash
cp .env.example .env
# Отредактируйте .env и вставьте ваш ключ
```

### Запуск тестов

```bash
python -m pytest tests/ -v
```

## Данные и интеграции

### Входные данные

- `messages.txt` — текстовый файл с обращениями студентов (по одному на строку)

### Внешние сервисы

| Сервис | Использование | Обязательность |
|--------|---------------|----------------|
| Google Gemini API | Классификация и генерация ответов (режим `--llm`) | Опционально |

### Безопасность

- API ключи хранятся в переменных окружения (никогда не коммитятся)
- Файл `.env` добавлен в `.gitignore`
- Локальный режим работает полностью без внешних вызовов

## Ограничения

- **Бесплатный тариф Gemini:** ограничение 5 запросов в минуту — при обработке большого количества обращений возможны задержки
- **Нет RAG и веб-поиска:** классификация основана только на локальных правилах или单一 LLM-вызове
- **Три категории:** система не поддерживает произвольные категории — только `справка`, `жалоба`, `другое`
- **Нет веб-интерфейса:** только CLI
- **Нет базы данных:** история хранится в JSON-файле
