# Классификатор обращений

Небольшой CLI-агент для автоматической обработки обращений студентов.

Система определяет категорию обращения — `справка`, `жалоба` или `другое` — и формирует короткий черновик ответа на русском языке.

## Запуск

```bash
git clone <repository>
cd <repository>

python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

Если используется LLM, перед запуском необходимо настроить соответствующий API key через переменную окружения.

## Архитектура

```text
messages.txt
     ↓
  Classifier
     ↓
 Validation
     ↓
   Router
  ↙   ↓   ↘
Info Complaint Other
  ↘   ↓   ↙
 Response
     ↓
Quality Check
     ↓
  Memory
```

Классификатор использует ограниченный набор категорий и структурированный результат. Перед выводом результат проходит проверку, а обращения с недостаточной уверенностью обрабатываются через безопасный fallback.

Лёгкая JSON-память сохраняет историю обработки обращений.

## Результат

На пяти тестовых обращениях система определяет:

```text
1. справка
2. жалоба
3. другое
4. жалоба
5. справка
```

Для каждого обращения дополнительно выводится черновик ответа на русском языке.
